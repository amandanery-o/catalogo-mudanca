# 📦 Catálogo de Mudança

Sistema de busca de itens para organização de mudança residencial.

## 🎯 Funcionalidades

- **Busca em tempo real** por qualquer termo (item, caixa, categoria, cômodo)
- **Filtros múltiplos** (cômodo, categoria, prioridade)
- **Código de cores** por prioridade (Alta, Média, Baixa)
- **Interface responsiva** (funciona em celular, tablet e desktop)
- **Funciona offline** (após carregamento inicial)

## 📊 Estatísticas

- **770 itens** catalogados 🎉
- **54 livros** organizados
- **716 itens de mudança** organizados
- **34 pares de calçados** da Amanda 👟
- Caixas numeradas de forma criativa (incluindo 29501, 1948, etc!)

## 🚀 Como usar

### Online
🌐 **Acesse:** https://amandanery-o.github.io/catalogo-mudanca/

### Local
1. Baixe os arquivos
2. Abra `index.html` no navegador
3. Pronto! A busca já está funcionando

## 📁 Arquivos

- `index.html` - Interface web de busca
- `catalogo_dados.json` - Base de dados com todos os itens
- `catalogo_mudanca.xlsx` - Planilha Excel do catálogo geral
- `catalogo_livros.xlsx` - Planilha Excel do catálogo de livros

## 🎨 Prioridades

- 🟨 **Alta** (144 itens) - Primeira noite, roupas essenciais, calçados
- 🟦 **Média** (556 itens) - Itens importantes mas não urgentes
